# Odin Recipes

This is my first project from The Odin Project's Foundations course. It's a simple recipe website built with HTML.

The website contains a main page with links to different recipes. Each recipe page includes a description, an image, a list of ingredients, and the steps to prepare the dish.

## What I Learned

- Creating and structuring HTML pages
- Working with headings, paragraphs, and lists
- Adding images to a webpage
- Creating links between pages
- Organizing files and folders

## Built With

- HTML
